老板原话八模块 → 产品入口与演示操作

1 总账
凭证录入、审核、过账、冲销、作废 → 总账/凭证管理及详情操作。
科目与辅助核算 → 基础档案/科目，凭证保留公司、船舶、往来方、部门。
结转、结账、反结账 → 总账/期末与结账，检查阻断、最近期间限制及原因日志。
总账、明细账、余额表 → 总账/总账与明细账，点击科目下钻。
三大报表 → 总账/三大财务报表，资产负债表、利润表、直接法现金流量表。

2 应收
预算内固定费 → 应收/合同与管理费，月费及首末月规则；月度船东账单防重复。
四类预算外按月实际费 → 已审核原票行自动收集，换旗作为其他子类；迟到费用保留原属月。
收款、核销、应收、账龄、客户对账 → 应收/收款、账龄及五类汇总下钻，CSV和打印。
固定管理服务费与运营拨款分别记录，不把旧船管成本自动当管理费收入。

3 应付
供应商发票 → 应付/供应商发票总单，头行分离，原编号防重，多币种、到期日及税额。
付款申请、支付状态 → 应付/付款申请与核销；审核与实际执行分离，多对多部分核销。
应付、到期、供应商对账 → 应付/到期应付与对账，回单通过付款核销来源显示。
BankSlip → 付款详情/附件，浏览器本地文件保存及下载。

4 资金与出纳
单船银行、现金 → 资金/银行与现金账户，主体与船舶分别关联。
银行导入与对账 → CSV预览、防重、部分匹配，不重复新增资金。
收支台账、余额调节表 → 独立页面，区分业务资金、银行对账记录及已过账总账。
船长备用金 → 划拨与消费分离。
拨款 → 计划与实际到账分离，非管理服务收入；收款用途分配与核销分离。
申请单、支票、汇票 → 资金/申请单与票据，审批后可关联付款申请兑付。

5 报销
提交、审核、部门归集 → 费用报销/员工报销及部门费用归集。
借款、冲账 → 员工借还款，报销详情冲同员工借款；剩余应付独立支付。
自动凭证 → 审核及冲借款生成凭证草稿，需审核过账。

6 固定资产
录入、台账 → 固定资产/资产卡片与台账，资本化门槛可配置。
折旧 → 本月直线法计提，重复计提阻断、残值控制、跨月处理。
报废、变更、盘点 → 资产详情可执行，报废生成凭证草稿，操作留痕。

7 发票与税务
单船/MSTS进销项发票 → 发票与税务/进销项台账，引用业务原票，避免重复录入。
简单税金统计与计提 → 税额统计及示例计提凭证；税率默认零，不进行真实申报。

8 基础档案与权限
船名与IMO、单船公司、船东付款银行 → 公司与账套、公司与船舶。
科目、部门、客户、供应商、员工 → 独立维护入口；旧业务编码与会计科目区分。
制单、审核、管理员 → 全量演示与权限演练；操作和账套范围受控，授权可维护。

保留旧项目内容
原Excel、原快照、旧SOFP、全部数据与公式检索报告、原始费用、192条业务编码、发现与源行溯源。
真实数据保持只读，历史未平差额不调平。旧业务URL跳转新模块或历史专区。

交付边界
这是可离线运行的浏览器产品原型，业务规则和权限在本地模拟。
正式数据库、服务端鉴权、生产审批、真实银行支付、正式会计及税务政策、税务申报和生产备份均未接入。
